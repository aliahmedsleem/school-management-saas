# Local development

## Backend (Windows PowerShell)

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:ENVIRONMENT="development"
$env:SECRET_KEY="replace-with-a-long-random-development-secret"
$env:DATABASE_URL="postgresql+psycopg://school:change-me@localhost:5432/school_saas"
.\.venv\Scripts\python.exe -m flask --app wsgi db init
.\.venv\Scripts\python.exe -m flask --app wsgi db migrate -m "initial schema"
.\.venv\Scripts\python.exe -m flask --app wsgi db upgrade
.\.venv\Scripts\python.exe -m flask --app wsgi bootstrap-demo --email admin@example.com
.\.venv\Scripts\python.exe -m flask --app wsgi run --debug
```

Run `flask db init` only once. Review autogenerated migrations before applying them.

## Frontend

```powershell
cd frontend
npm install
npm run dev
```

## API

- GET /api/health
- POST /api/auth/login (email, password, tenant_id)
- GET /api/auth/me
- POST /api/auth/logout (X-CSRF-Token required)
- GET /api/schools
- POST /api/schools (name; owner role; X-CSRF-Token required)
- GET /api/subscription

The current frontend is a standalone UI preview, not wired to these endpoints. Never use production or real student data with this prototype.
